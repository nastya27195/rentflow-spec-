# Описание проекта
## Проблема и цели
Управляющие компании с портфелем от 10 объектов тратят до 30% времени менеджеров на ручной биллинг.
Цели MVP: автоматически формировать счета по всем активным договорам; принимать оплату онлайн;
автоматически фиксировать просрочки и начислять пени; давать менеджеру единый экран контроля дебиторки.
## Метрики успеха (MVP)
| Метрика | Целевое значение |
|---|---|
| Доля счетов, выставленных автоматически | ≥ 95% |
| Время менеджера на биллинг | −70% |
| Доля онлайн-оплат | ≥ 60% |
| Средний срок просрочки | −30% |
## Границы MVP
Входит: объекты, арендаторы, договоры, автоматический биллинг, онлайн-оплата, просрочки и пени,
уведомления, задачи менеджера. Не входит: бухгалтерская интеграция, ЭДО, мобильное приложение.
