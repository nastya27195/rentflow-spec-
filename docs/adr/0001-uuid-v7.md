# ADR-0001: UUID v7 как первичные ключи

**Статус:** принято, 2026-09-20

**Контекст и решение.** Генерация в приложении, монотонность v7 без hot-spot в B-tree, безопасная публикация id в события.

**Последствия.** Отражено в `db/schema.sql` v2.0; см. `docs/08_data_model.md`, `docs/10_kafka_events.md`, `docs/12_security.md`.
