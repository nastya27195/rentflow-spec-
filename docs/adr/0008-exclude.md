# ADR-0008: EXCLUDE на периоды договоров

**Статус:** принято, 2026-09-20

**Контекст и решение.** Проверка в коде подвержена гонкам; btree_gist + daterange даёт атомарную гарантию, фильтр по статусу сохраняет черновики и историю.

**Последствия.** Отражено в `db/schema.sql` v2.0; см. `docs/08_data_model.md`, `docs/10_kafka_events.md`, `docs/12_security.md`.
