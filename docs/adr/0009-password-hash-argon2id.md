# ADR-0009. Хранение пароля в user_account.password_hash (argon2id)

**Статус:** принято, 2.0.8

## Контекст
В v2.0.x у `user_account` не было поля для учётных данных, хотя `docs/12_security.md` описывает JWT-аутентификацию по логину и паролю.

## Решение
Добавлены `password_hash TEXT` (argon2id: m=64 MiB, t=3, p=1), `invited_at`, `last_login_at`. Поле NULL до принятия приглашения; CHECK `ck_user_active_has_password` не позволяет активному пользователю существовать без пароля и без открытого приглашения. Хэш не возвращается API и маскируется в `audit_log`.

## Последствия
Внешний SSO при необходимости добавляется отдельной таблицей `user_identity`; поле остаётся NULL.
