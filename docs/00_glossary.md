# Глоссарий
| Термин | Значение |
|---|---|
| Объект (Property) | Единица недвижимости, сдаваемая в аренду |
| Арендатор (Tenant) | Юр. или физ. лицо — сторона договора |
| Договор (Contract) | Соглашение об аренде с периодом биллинга и ставкой |
| Счёт (Invoice) | Начисление за расчётный период по договору |
| Платёж (Payment) | Факт оплаты счёта через платёжный шлюз |
| Пеня (Penalty) | Начисление за просрочку, % от долга в день |
| Задача (Task) | Ручная работа менеджера, создаваемая системой |
| Billing-job | Ежедневный cron 00:05, формирующий счета |
| Idempotency-Key | Заголовок для защиты от повторной инициации оплаты |
| Webhook | Callback платёжного шлюза о результате оплаты |
